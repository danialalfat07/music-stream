================================================================
KONTEKS MASALAH
================================================================
Pada versi 3.2.4, fitur Native Bridge (`NativePlayback`) mati total. 
Aplikasi mendeteksi dirinya sebagai Web Browser (iFrame mode) dan 
menolak fitur offline.

Penyebabnya: Penambahan fungsi `migrateLegacyCaches()` di dalam 
`MainActivity.onCreate()` kemungkinan besar melempar Exception 
(misal karena akses file), sehingga eksekusi `onCreate` terhenti 
sebelum sempat memanggil `addJavascriptInterface()`.

User meminta:
1. REVERT total logika migrasi cache yang rumit tersebut.
2. Buang pemanggilan `migrateLegacyCaches` dari `MainActivity`.
3. Cukup ubah direktorinya saja secara SIMPEL: dari `getCacheDir()` 
   ke `getExternalFilesDir(null)`. Biarkan file lama di cache (nanti 
   dihapus OS), yang penting file baru masuk ke folder data.
