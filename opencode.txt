MASALAH (Berdasarkan Screenshot User)
================================================================
Saat user mengklik lagu (contoh: "Teh Hijau"), lagu tersebut 
langsung masuk ke Recently Played dengan durasi "--:--".
Padahal setelah lagu berjalan beberapa detik, player sudah tahu 
durasi aslinya (contoh: "3:32" atau 212 detik).

Akar masalah: `pushHistory` menyimpan data terlalu awal (saat 
durasi engine masih 0). API search juga sering tidak menyertakan 
durasi di metadata.

Ekspektasi: Jika durasi belum diketahui saat disimpan, aplikasi 
harus otomatis meng-update record history (backfill) begitu 
player berhasil memuat durasi lagu tersebut.

================================================================
TUGAS FIX (public/app.js)
================================================================

F1. BUAT FUNGSI BACKFILL DI LIBRARY
    Tambahkan fungsi baru di objek `Library` (dekat fungsi 
    `pushHistory`):
    
    updateHistoryDuration(videoId, durationSecs) {
        if (!videoId || !durationSecs || durationSecs <= 0) return;
        
        // 1. Update Library.stats
        const st = store.get('stats', {});
        if (st[videoId]) {
            st[videoId].duration = durationSecs;
            store.set('stats', st);
        }
        
        // 2. Update History (hanya jika record belum punya durasi)
        const h = this.history;
        let changed = false;
        for (let i = 0; i < h.length; i++) {
            if (h[i].videoId === videoId) {
                if (!h[i].duration) { // Hanya update jika kosong
                    h[i].duration = durationSecs;
                    changed = true;
                }
            }
        }
        if (changed) {
            store.set('hist', h);
            // Opsional: picu re-render UI jika sedang di halaman search
            // (misal jika ada fungsi renderView atau update DOM 
            // untuk recently played).
        }
    }

F2. PANGGIL FUNGSI BACKFILL SAAT DURASI TERSEDIA
    Cari tempat di mana aplikasi memperbarui durasi UI player 
    (biasanya di event `timeupdate`, `durationchange`, atau di 
    dalam fungsi tick/interval player yang meng-update teks 
    "0:04 / 3:32").
    
    1. Cari event listener `audio.addEventListener('durationchange')` 
       atau `video.addEventListener('loadedmetadata')`.
    2. ATAU cari fungsi yang mengecek `Player.audio.duration` / 
       `Player.native.dur`.
    3. Di tempat tersebut, tambahkan pemanggilan:
       `Library.updateHistoryDuration(Player.current.videoId, durasiAktual);`
       (Pastikan konversi ke detik bulat jika perlu).

    *PENTING*: Pastikan fungsi ini tidak dipanggil berulang-ulang 
    setiap detik jika durasi tidak berubah. Cukup panggil saat 
    durasi pertama kali terdeteksi > 0 (misal via flag `_durationFixed` 
    di object Player atau pengecekan sederhana).

F3. RENDER ULANG (UI UPDATE)
    Agar user langsung melihat perubahan tanpa harus reload halaman:
    - Jika `updateHistoryDuration` dipanggil dan sedang berada di 
      halaman Search (`location.hash === '#/search'`), panggil 
      fungsi render ulang (misal `viewSearch()` atau render ulang 
      elemen Recently Played).
    - Jika ini terlalu kompleks, cukup pastikan saat user pindah 
      tab lalu kembali ke Search, datanya sudah terbarui (karena 
      membaca ulang dari localStorage).
