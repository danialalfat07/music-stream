## Task

Removed native Home and native Back to PiP logic.

Widget PiP opening remains available through existing widget button paths and navbar Home intercept. Navbar Back remains normal history navigation.

## Removed from native

- Removed `NativeStateBridge` class from `MainActivity.java`.
- Removed `stateBridge` Activity field.
- Removed WebView registration for `NativeState`.
- Removed `onUserLeaveHint()` override. Native Home now minimizes normally.
- Removed native Back fast path that read `backShouldPip` and called `showPipOnce()`.
- Removed Home-page native Back branch that opened PiP when a current track existed.
- Removed obsolete `hasCurrent` state from native Back JavaScript payload and parser.
- Removed obsolete `showPipOnce()` fallback from native Back handling.
- Kept existing `onBackPressed()` override because it handles pre-existing modal, Now Playing, settings, help, WebView history, and task-back behavior. It no longer opens PiP.
- Kept existing `onPictureInPictureModeChanged()` because it drives pre-existing PiP rendering, native PiP view visibility, WebView sync, artwork, lyrics, and diagnostics. No feature-specific NativeState or PIPNATIVE logic remains there.

## Removed from JS

- Deleted `syncNativeState()` completely.
- Deleted all `syncNativeState()` call sites:
  - Track start.
  - Hash change.
  - Settings Widget toggle.
  - App initialization.
- Deleted all `window.NativeState` and `NativeState.set*` usage.
- Restored navbar Back to original behavior:

```js
$('#nav-back').addEventListener('click', () => history.back());
```

- Kept navbar Home Widget-on-Home intercept unchanged.
- Kept `showPipOnce()`, `openFloatWidget()`, widget button handlers, PiP rendering, canvas, and keep-alive logic unchanged.
- Kept `isPipVisible()`. It remains required by progress rendering and WebView PiP keep-alive paths.

## Removed from manifest

- Removed `android:enableOnBackInvokedCallback="false"`. It was added only to force the feature-specific native Back path.

## Pre-existing items left alone

- `MainActivity.onBackPressed()` overall override. It existed before this feature for overlay and WebView navigation handling.
- `MainActivity.onPictureInPictureModeChanged()` and its PiP rendering logic.
- `NativePlayback` bridge and its `enterPip()` method. Widget button path still uses this bridge.
- `VisionOsHarness` entries `native-state` and `aNativeState()`. These are diagnostic harness actions, not `NativeState` bridge references and were pre-existing.
- Existing `pushNativeState()` function and `[NATIVE_STATE]` comment. These refer to playback notification state, not removed Home/Back state bridge.
