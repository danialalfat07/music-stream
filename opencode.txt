MASALAH BERDASARKAN SCREENSHOT USER
================================================================
1. Di Recently Played, durasi masih "--:--".
2. Di Search Results (Lagu/Video), durasi masih "--:--" di ujung
   kanan, DAN teks durasi masih menempel di baris bawah (subtitle).
   Contoh format subtitle dari API:
   - "Erlangg a • sesi potret • 3.22 • ..."
   - "éñau • 5.06 • 102 ... x ditonton"
   - "Tulus • Teh Hijau • 3.33 • ..."
   Perhatikan pemisahnya adalah " • " (spasi, bullet, spasi).
   Durasi menggunakan titik (3.22), bukan titik dua (3:22).

TUGAS FIX (public/app.js)
================================================================

F1. PERBAIKI PARSING SUBTITLE (trackRowHTML)
    Cari fungsi `trackRowHTML` (sekitar baris 4164).
    Saat ini agent sebelumnya gagal memisahkan durasi dari subtitle.
    Lakukan logika berikut di dalam `trackRowHTML`:
    
    1. Ambil `it.subtitle`.
    2. Pecah string berdasarkan pemisah " • ".
    3. Cari segmen yang berbentuk durasi. Regex durasi:
       /^\d{1,2}[:.]\d{2}$/  (mendeteksi 3:22, 3.22, 1:02:30)
    4. Simpan durasi yang ditemukan ke variabel `parsedDuration`.
    5. Buang segmen durasi tersebut dari array hasil split.
    6. Gabungkan kembali sisa segmen dengan " • ".
       -> Ini akan menjadi subtitle baru TANPA durasi.
    7. Tampilkan sisa segmen ini di baris bawah (artist & views).
    
    *Catatan*: Jika API mengirim `it.duration` secara terpisah,
    prioritaskan `it.duration`. Jika kosong, gunakan
    `parsedDuration` dari dalam subtitle.

F2. UPDATE RENDER DURASI (.tdur)
    - Pastikan variabel durasi (dari `it.duration` atau
      `parsedDuration`) di-format dengan benar (ubah titik menjadi
      titik dua jika perlu, misal "3.22" -> "3:22").
    - Render di `<span class="tdur">...</span>`.
    - HAPUS fallback "--:--" JIKA durasi berhasil di-parse.
      (Biarkan "--:--" hanya jika benar-benar tidak ada durasi
      sama sekali).
