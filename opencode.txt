================================================================
KOREKSI MASALAH DARI VERSI 3.2.3
================================================================
1. Pada versi 3.2.3, file INCOMPLETE (.part) dipindah menggunakan 
   `context.getFilesDir()`. Ini salah, karena getFilesDir() adalah 
   Internal Storage yang tidak terlihat di file manager (Android/data).
   Seharusnya gunakan `context.getExternalFilesDir(null)`.
   
2. Lagu offline yang sudah COMPLETE (.webm) dan file metadata-nya 
   (.song.json, .art, .lyrics.json) TIDAK ikut dipindah. Akibatnya
   saat user "Clear Cache", lagu offline mereka hilang.

================================================================
TUGAS IMPLEMENTASI
================================================================

A1. GANTI SEMUA PATH KE EXTERNAL FILES DIR
    - Buka VisionOsCache.java dan SongCache.java.
    - Cari semua pemanggilan `context.getFilesDir()` dan `context.getCacheDir()`.
    - Ganti semuanya menjadi `context.getExternalFilesDir(null)`.
    - Pastikan folder utamanya dinamai secara terpusat, misal:
      `new File(context.getExternalFilesDir(null), "visionos_media")`.
    - Struktur folder baru yang diharapkan:
      * .../Android/data/com.dnialify.musicstream/files/visionos_media/complete/
      * .../Android/data/com.dnialify.musicstream/files/visionos_media/incomplete/
      * .../Android/data/com.dnialify.musicstream/files/visionos_media/meta/

A2. MIGRASI FILE LAMA (WAJIB!)
    - Buat fungsi `migrateLegacyCaches(Context c)` di SongCache.java.
    - Fungsi ini harus mengecek 2 lokasi lama:
      1. `getCacheDir()/visionos_cache` (tempat file COMPLETE yang bikin hilang)
      2. `getFilesDir()/incomplete_cache` (tempat file INCOMPLETE dari v3.2.3)
    - Jika ada file di lokasi lama, pindahkan (copy + delete) ke lokasi
      baru di `getExternalFilesDir()`.
    - Panggil fungsi migrasi ini sekali saat aplikasi pertama kali start
      (misal di NativeAudioEngine atau MainActivity).

A3. PASTIKAN HAPUS CACHE TIDAK MENGHAPUS OFFLINE
    - Karena file COMPLETE sekarang ada di `getExternalFilesDir()`,
      OS Android tidak akan menyentuhnya saat user melakukan "Clear Cache".
    - Pastikan fungsi "Hapus Cache" di dalam aplikasi (jika ada tombolnya)
      hanya menghapus file dari folder `incomplete/` dan tidak menyentuh
      folder `complete/`.

A4. PERBAIKI LOGIKA MOVE FILE
    - Karena semua file sekarang berada di dalam `getExternalFilesDir()`
      (satu partisi penyimpanan yang sama), fungsi `moveFile()` bisa
      menggunakan `renameTo()` secara aman dan cepat, menghindari copy+delete
      yang memakan waktu.
