--- F2: loadArtwork (baris ~230-245) ---

SEBELUM:
    private void loadArtwork(String url) {
        if (url == null || url.isEmpty() || url.equals(artworkLoadedUrl)) return;
        artworkLoadedUrl = url;
        new Thread(() -> {
            try {
                Bitmap loaded = BitmapFactory.decodeStream(new java.net.URL(url).openStream());
                if (loaded == null) return;
                artworkBitmap = loaded;
                if (notifications != null) notifications.invalidate();
            } catch (Exception ignored) {}
        }).start();
    }

SESUDAH (tambah overload dgn callback + pindah set loadedUrl ke success):
    private void loadArtwork(String url) {
        loadArtwork(url, null);
    }

    private void loadArtwork(String url, PlayerNotificationManager.BitmapCallback callback) {
        if (url == null || url.isEmpty() || url.equals(artworkLoadedUrl)) return;
        new Thread(() -> {
            try {
                Bitmap loaded = BitmapFactory.decodeStream(new java.net.URL(url).openStream());
                if (loaded == null) {
                    Log.w("PlaybackMediaSession", "artwork decode null url=" + url);
                    return;  // tidak set artworkLoadedUrl -> boleh retry
                }
                artworkBitmap = loaded;
                artworkLoadedUrl = url;   // <-- pindah ke sini, setelah sukses
                if (notifications != null) notifications.invalidate();
                if (callback != null) callback.onBitmapLoaded(loaded);
            } catch (Exception e) {
                Log.w("PlaybackMediaSession", "artwork load fail url=" + url + " err=" + e);
            }
        }).start();
    }

FIX 8: QUEUE RACE (NativeAudioEngine.java)
============================================================

File: android/app/src/main/java/com/dnialify/musicstream/NativeAudioEngine.java
Baris ~515-545 (startExoUrl):

MASALAH: JS panggil nativeSetQueue() lalu nativePlay() lewat dua bridge call
berurutan. Tidak ada jaminan atomic. Kalau nativePlay sampe duluan, queue
kosong -> ids.size()==1 -> setMediaSource(single) -> next/prev notif hilang.

SOLUSI: di setQueue() (baris ~485-515), kalau state == IDLE/RESOLVING
(belum playing), TETAP simpan queue. Tambah flag `queueReady`. Di startExoUrl,
kalau queueReady false DAN ada pending ids dari metadata (dari setQueue yang
belum sampe), tunggu max 500ms:

Di startExoUrl, SEBELUM build ids list, tambah:

        // tunggu queue mirror max 500ms (JS bridge bisa race)
        long waitStart = System.currentTimeMillis();
        while (queue.isEmpty() && System.currentTimeMillis() - waitStart < 500) {
            try { Thread.sleep(50); } catch (InterruptedException ignored) {}
        }

CATATAN: startExoUrl dipanggil dari main thread. Thread.sleep di main
thread akan ANR kalau >5s. 500ms masih aman, tapi lebih baik pindah
wait ke thread resolveAndStart yang sudah worker thread. Cek lagi
alur: resolveAndStart worker -> main.post(startExoUrl). Kalau begitu,
pindah wait ke resolveAndStart sebelum main.post.

ALTERNATIF LEBIH BERSIH: bikin satu bridge call nativePlayWithQueue(
videoId, title, artist, artwork, queueJson, currentIndex, startSeconds)
yang set queue + play dalam satu @JavascriptInterface method, sehingga
tidak ada race. Update MainActivity.PlaybackBridge + public/app.js
(nativePlayAt diganti nativePlayAtWithQueue). Kalau opsi ini dipilih,
pastikan public/app.js sudah update panggilan dan tidak break fallback.

PILIH yang paling minimal. Default: tunggu 500ms di worker thread
resolveAndStart sebelum panggil startExoUrl.

Kalau INSTALL_FAILED_UPDATE_INCOMPATIBLE, tampilkan error + JANGAN
uninstall otomatis. Lapor ke user dulu.

--- B3: Copy ke sdcard ---
Baca versionName dari:
  cd android && ./gradlew -q :app:printVersionName
  (kalau task tidak ada, baca dari build.gradle computedVersionName,
   fallback ke package.json webVersion)
Format: 2.3.5-build.<RUN_NUM> atau 2.3.5

adb shell mkdir -p /sdcard/Download/Dnialify
adb push android/app/build/outputs/apk/debug/app-debug.apk \
    /sdcard/Download/Dnialify/dnialify-<versionName>.apk

GANTI <versionName> dengan versi aktual, contoh:
  /sdcard/Download/Dnialify/dnialify-2.3.5-build.42.apk
