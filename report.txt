GAP #1 - PERBEDAAN VERSI APK vs WEB (PENTING)
  Work order F3.5 meminta `dumpsys ... versionName` menunjukkan
  3.5.2. Kenyataannya versionName=3.2.0. Sebab: `bump.js` (yang
  work order suruh pakai, `npm run bump 3.5.2`) hanya menaikkan
  `package.json.webVersion`, sedangkan `versionName` Android
  dibaca dari `package.json.version` (android/app/build.gradle
  baris 11-22). Repo ini memang memisahkan versi web dan versi
  APK ("bump web 3.5.1", dst). Saya TIDAK menaikkan field
  `version` secara manual karena work order melarang mengubah
  package.json dengan cara selain `npm run bump`. Jadi: web =
  3.5.2, APK = 3.2.0. Bila user memang ingin APK 3.5.2, perlu
  arahan terpisah.

GAP #2 - X NATIVE TIDAK DIKODEKAN
  Tombol X kedua bukan elemen HTML/JS, melainkan kontrol bawaan
  `input[type=search]`. Work order menyuruh "hapus dari HTML/JS",
  tapi tidak ada yang bisa dihapus di sana. Fix dilakukan di CSS
  (sembunyikan). Sudah dikonfirmasi user sebelum dikerjakan.

GAP #3 - RECORD HISTORY LAMA
  Record di localStorage yang dibuat SEBELUM fix dan tanpa field
  durasi akan tetap "--:--" bila tidak ada data pengganti. Work
  order melarang migrasi massal localStorage, jadi ini dibiarkan
  (record baru sudah benar; record lama bisa jadi benar bila
  subtitle memuat durasi atau stats memuatnya).

GAP #4 - `_queueSource` (pekerjaan Mix sebelumnya)
  Tombol Play/Shuffle di halaman Favorites (public/app.js baris
  ~6109/6115) masih mengirim source default 'single'. Belum

  pekerjaan ini (di luar scope). Menunggu arahan.

GAP #5 - `webVersion` vs `version` konsistensi
  Sebelum pekerjaan ini: package.json.version=3.1.0,
