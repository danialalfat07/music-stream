SESUDAH (fungsi lengkap):

  pushHistory(song) {
    let h = this.history.filter((s) => s.videoId !== song.videoId);
    // L65 (R1/R2): resolusi durasi DULU, baru bersihkan subtitle.
    // Urutan pengambilan durasi:
    //   1) field song.duration/dur/lengthSeconds/length
    //   2) segmen durasi DI DALAM song.subtitle ("3.22" / "3:22")
    //   3) segmen durasi di dalam song.title (jika ada)
    //   4) stats lokal
    //   5) durasi engine yang sedang berjalan
    let dur = song.duration ?? song.dur ?? song.lengthSeconds ?? song.length;
    if (dur == null || dur === '') {
      const dsub = durationFromSubtitle(song.subtitle);
      if (dsub) dur = dsub;
    }
    if (dur == null || dur === '') {
      const dtitle = durationFromSubtitle(song.title);
      if (dtitle) dur = dtitle;
    }
    if (dur == null || dur === '') {
      try {
        const st0 = this.stats[song.videoId];
        if (st0 && st0.duration) dur = st0.duration;
      } catch {}
    }
    if (dur == null || dur === '') {
      const live =
        (Player.native && Player.native.dur && Number(Player.native.dur)) ||
        (Player.audio && Number(Player.audio.duration)) ||
        0;
      if (live > 0 && live <= 43200) dur = live;
    }
    // Normalisasi "3.22" -> "3:22" agar konsisten saat dibaca ulang.
    const finalDuration =
      dur != null && dur !== '' ? normalizeDuration(dur) : '';
    const rec = { ...song };
    // R1: persist ke stats DULU supaya fallback trackRowHTML hidup.
    const st = store.get('stats', {});
    const k = song.videoId;
    if (!st[k])
      st[k] = {
        title: song.title,
        artist: song.artist || '',
        thumbnail: song.thumbnail,
        plays: 0,
        secs: 0,
        last: 0,
      };
    if (finalDuration) {
      rec.duration = finalDuration;
      st[k].duration = finalDuration;
      // R2: subtitle HANYA dibersihkan bila durasi benar-benar valid.
      if (rec.subtitle) {
        const { rest, plays } = splitSubtitle(rec.subtitle);
        rec.subtitle = [rest, plays].filter(Boolean).join(' \u2022 ');
      }
    }
    h.unshift({ ...rec, playedAt: Date.now() });
    store.set('hist', h.slice(0, 100));
    // play stats (local scrobble)
    st[k].plays++;
    st[k].last = Date.now();
    st[k].title = song.title;
    st[k].thumbnail = song.thumbnail;
    store.set('stats', st);
  },
----------------------------------------------------------------

PEMETAAN KE TUGAS F2:
  1. Ambil durasi dari song.subtitle sebelum bersihkan  -> baris `const dsub = durationFromSubtitle(song.subtitle)`.
  2. Simpan ke variabel `finalDuration`                  -> `const finalDuration = ...`.
  3. Simpan ke Library.stats[videoId].duration           -> `st[k].duration = finalDuration;`
     (ditulis ke store 'stats' yang sama, sehingga fallback
      trackRowHTML di masa depan bisa membacanya).
  4. Hanya bersihkan subtitle bila finalDuration valid    -> dibungkus `if (finalDuration) { ... }`.
     Jika durasi kosong, subtitle TIDAK dibuang (tetap utuh).
  5. Simpan ke record history                            -> `rec.duration = finalDuration;`

dievaluasi langsung dari sumber public/app.js, lalu diuji:

  INPUT                                            DURASI  SUBTITLE HASIL
  ----------------------------------------------  ------  ---------------------------
  "Tulus • Sesi Potret • 3.22"                     202s  "Tulus • Sesi Potret"
  "enau • 5.06 • 102 jt x ditonton"                306s  "enau • 102 jt x ditonton"
  "Seli vormel • sesi potret • 844 jt pemutaran"     0s  (tidak diubah — lihat catatan)
  "Artist • Album"                                   0s  "Artist • Album"

CATATAN PENTING (perilaku BARU yang benar):
  - Kasus "Tulus • Sesi Potret • 3.22": durasi 3.22 -> 202s berhasil
    diambil, subtitle dibersihkan menjadi "Tulus • Sesi Potret".
  - Kasus "Seli vormel • ... • 844 jt pemutaran" (tanpa durasi): durasi
    = 0 -> subtitle TIDAK dibersihkan. Ini sesuai R2: jangan buang teks
    subtitle bila durasi tidak valid. Viewcount tetap utuh.
  - Kasus "Artist • Album" (tanpa durasi): subtitle utuh, tidak ada
    yang hilang.
